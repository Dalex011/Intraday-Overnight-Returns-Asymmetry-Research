# Intraday-Overnight-Returns-Asymmetry-Research
Ongoing investigation regarding intraday-overnight returns asymmetry in the US and Chilean stock market.

This is my first ever GitHub repository, so I apologize in advance for any mistake I can make while I learn to navigate the platform!

The main goal behind this investigation is to experiment with overnight-intraday returns behaviour. I intend to learn about the different risk-to-reward characteristics of these timeperiods, explore what may cause them, and attempt to find tradable strategies that I can apply to generate profits.

To achieve this goal I plan on using mainly Python coupled with the appropriate libraries, Excel, and Bloomberg data when needed extracted from the terminals of my university.

Although this is a topic that has been extensively researched for the past 50 or so years, I will still attempt to find interesting results and learn from my mistakes along the way.
